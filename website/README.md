# CSF-dementia-website

CSF Proteomics Dementia Database - 脑脊液蛋白组学痴呆数据库

## 项目简介

这是一个专业的生物信息学数据库网站，用于展示和分析脑脊液蛋白组学与痴呆相关的研究数据。

## 功能特点

- 蛋白质查询与详情展示
- 差异表达火山图分析
- WGCNA共识模块分析
- Meta分析结果展示
- 多语言支持（中文/英文）
- 白天/夜间模式切换
- 响应式设计

## 技术栈

- 后端：Python Flask
- 前端：HTML5, CSS3, JavaScript
- 数据可视化：Plotly.js
- 样式：毛玻璃效果 (Glassmorphism)
