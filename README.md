# CSFdementia V3

This is the code repository for an article by Shanjie Luan.

## Project Structure

```
V3/
├── main/           # Main analysis workflows
├── convert&plot/   # Data conversion and plotting scripts
└── machinelearning/ # Machine learning models and evaluation
```

### main/
Main analysis workflows including:
- Data combination and preprocessing
- Correlation analysis
- Consensus WGCNA analysis
- Meta-analysis

### convert&plot/
Data conversion and visualization scripts including:
- Heatmap generation
- GOKEGG enrichment visualization
- PCA analysis
- Single cell analysis
- Interaction plots

### machinelearning/
Machine learning models and evaluation:
- Model training and evaluation
- Biomarker comparison
- SHAP analysis
- Model application guide

## Requirements

### R Packages
- WGCNA
- clusterProfiler
- ggplot2
- dpo3
- tidyr

### Python Packages
- pandas
- numpy
- scikit-learn
- matplotlib
- seaborn
